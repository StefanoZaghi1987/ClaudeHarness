# Effort escalation

Stay at the default effort. Recommend raising it only when the task is one of:
- deep multi-file debugging
- an architecture decision with real trade-offs
- security-critical review
- a final verification pass before delivery

When one applies, recommend the specific `/effort` level (usually `xhigh`) with a
one-line justification, and wait for the user to set it — never assume it is active.
For bulk exploration or lookup work delegated to subagents, prefer the `haiku` model.
